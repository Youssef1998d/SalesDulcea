# Dulcéa Sales Tracker

## Deploy on Vercel (5 minutes)

1. Go to https://vercel.com and create a free account
2. Click "Add New Project"
3. Click "Upload" (no GitHub needed)
4. Drag and drop the entire `dulcea-tracker` folder
5. Click Deploy — done!

You get a URL like: https://dulcea-tracker.vercel.app

## Add to phone home screen

### iPhone (Safari):
1. Open your Vercel URL in Safari
2. Tap the Share button (square with arrow)
3. Tap "Add to Home Screen"
4. Tap "Add"

### Android (Chrome):
1. Open your Vercel URL in Chrome
2. Tap the 3-dot menu
3. Tap "Add to Home Screen"
4. Tap "Add"

## Data
- All data is saved in your browser's localStorage
- Data persists as long as you don't clear browser data
- Use the CSV export button to back up your data regularly
